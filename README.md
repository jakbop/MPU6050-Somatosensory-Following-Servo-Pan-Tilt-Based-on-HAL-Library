# MPU6050 双轴舵机云台控制系统

基于 STM32F103C8 微控制器的 MPU6050 六轴传感器与双舵机云台控制项目。

## 项目简介

本项目实现了一个稳定的双轴云台系统，使用 MPU6050 六轴传感器（加速度计+陀螺仪）实时获取姿态数据，通过互补滤波器融合数据计算欧拉角，并驱动两个舵机对云台进行实时姿态跟踪控制。

## 硬件组成

- **主控芯片**：STM32F103C8T6（Cortex-M3 内核）
- **姿态传感器**：MPU6050（3轴加速度计 + 3轴陀螺仪）
- **舵机**：
  - 俯仰轴：180° 舵机
  - 航向轴：270° 舵机
- **开发环境**：Keil MDK-ARM + STM32CubeMX

### 主要功能模块

#### 1. MPU6050 驱动 (`mpu6050.c`)

**功能特性：**
- 传感器初始化配置
- 原始加速度计和陀螺仪数据读取
- 互补滤波器姿态融合

**关键参数：**
- 加速度计量程：±8g
- 陀螺仪量程：±2000°/s
- I2C 通信速率：400kHz
- 互补滤波系数：α = 0.96（陀螺仪占96%，加速度计占4%）

**主要函数：**
```c
// 初始化 MPU6050
void MPU6050_Init(void);

// 读取原始数据
void MPU6050_Read_Raw(int16_t *ax, int16_t *ay, int16_t *az,
                      int16_t *gx, int16_t *gy, int16_t *gz);

// 获取欧拉角（横滚角、俯仰角、偏航角）
void MPU6050_Get_Angles(float *roll, float *pitch, float *yaw);
```

#### 2. 舵机控制 (`servo.c`)

**功能特性：**
- PWM 信号生成（50Hz 频率）
- 角度到脉冲宽度的线性映射
- 角度范围限制保护

**舵机参数：**
- 控制频率：50Hz（周期 20ms）
- 脉冲范围：500μs ~ 2500μs
- 俯仰舵机：0° ~ 180°
- 航向舵机：0° ~ 270°

**主要函数：**
```c
// 舵机初始化（归中位置）
void Servo_Init(void);

// 设置俯仰舵机角度（0~180°）
void Servo_Pitch_SetAngle(float angle);

// 设置航向舵机角度（0~270°）
void Servo_Yaw_SetAngle(float angle);
```

#### 3. 主控制逻辑 (`main.c`)

**控制流程：**
1. 系统初始化（时钟、外设）
2. MPU6050 初始化
3. 舵机初始化（归中）
4. 主循环（50Hz 更新频率）：
   - 获取当前欧拉角
   - 角度范围限制
   - 驱动对应舵机

**控制映射：**
- 俯仰角 (pitch)：[-90°, +90°] → [0°, 180°]
- 偏航角 (yaw)：[-135°, +135°] → [0°, 270°]

## 姿态解算原理

### 互补滤波器

本项目采用互补滤波器融合加速度计和陀螺仪数据：

```
当前角度 = α × (上一时刻角度 + 陀螺仪角速度 × 时间差) + (1-α) × 加速度计直接计算角度
```

其中：
- α = 0.96（陀螺仪权重）
- 1-α = 0.04（加速度计权重）

**优点：**
- 算法简单，计算量小
- 实时性好
- 兼具加速度计的静态稳定性和陀螺仪的动态响应性

### 加速度计直接计算角度

```c
// 俯仰角
pitch = arctan(-ax / sqrt(ay² + az²)) × 180°/π

// 横滚角
roll = arctan(ay / az) × 180°/π
```

## 系统配置

### 时钟配置
- 外部晶振 (HSE)：8MHz
- PLL 倍频：×9
- 系统时钟：72MHz
- APB1 时钟：36MHz
- APB2 时钟：72MHz

### TIM4 PWM 配置
- 预分频器：71（72MHz / 72 = 1MHz）
- 自动重装载值：19999（周期 = 20000 × 1μs = 20ms）
- PWM 频率：50Hz

## 扩展建议

1. **添加卡尔曼滤波**：使用卡尔曼滤波器替代互补滤波器，获得更好的滤波效果
2. **增加 UART 输出**：通过串口输出姿态数据，便于调试和可视化
3. **添加 OLED 显示**：在本地 OLED 屏幕上实时显示角度信息
4. **增加 PID 控制**：引入 PID 控制算法，提高云台跟随精度
5. **低功耗优化**：在不需要高精度姿态时降低采样频率

## 注意事项

- MPU6050 需要水平放置并静止一段时间进行初始校准
- 舵机电源要足够稳定，建议使用独立电源供电
- yaw 角由纯积分得到，会存在漂移，需要定期校准或使用磁力计辅助
- 控制周期固定为 20ms（50Hz），不建议随意更改
